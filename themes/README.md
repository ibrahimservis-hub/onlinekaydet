# Site temaları (30)

- `html/` — 30 hazır tema (1–6 el yapımı, 7–30 `gen.py` ile üretilir). Bağlantı yer tutucusu: `__PORTAL_URL__` (yayında firmanın müşteri portalı adresiyle değiştirilir).
- `gen.py` — 7–30 numaralı temaları üretir: `python3 gen.py`.
- `panel/themes.json` — her temanın renk paleti (koyu, vurgu, yumuşak, köşe yarıçapı). Müşteri sayfaları (ödeme, teklif, portal) markayı buradan alır.
